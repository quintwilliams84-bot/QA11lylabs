What the free scan checks

Our automated scan tests for the most common and impactful WCAG 2.2 violations.

  • Color Contrast

    Flags text and UI elements that fail WCAG 2.2 AA contrast ratio requirements (4.5:1 for normal text, 3:1 for large text and UI components).

  • Missing Alt Text

    Identifies images, icons, and decorative elements that lack appropriate alternative text or aria-label attributes.

  • Form Labels

    Detects form inputs, selects, and textareas that are missing associated labels or aria-labelledby associations.

  • Heading Structure

    Checks for missing H1, skipped heading levels, and heading elements used for visual styling rather than semantic structure.

  • Keyboard Accessibility

    Identifies interactive elements that lack focus styles, are not reachable by keyboard, or create focus traps.

  • ARIA Usage

    Flags invalid ARIA roles, missing required ARIA attributes, and deprecated ARIA patterns that can break screen reader navigation.

What automated scanning can't catch

Automated tools find roughly 30–40% of accessibility issues. The rest require human judgment.

What automated scans miss

  • ✕ Screen reader reading order and verbosity issues
  • ✕ Cognitive load and plain language failures
  • ✕ Context-dependent ARIA patterns
  • ✕ Touch target adequacy on mobile devices
  • ✕ Video caption accuracy and audio descriptions

What expert manual testing adds

  • ✓ Real-world JAWS, NVDA, VoiceOver & TalkBack testing
  • ✓ Keyboard-only navigation walkthroughs
  • ✓ Cognitive accessibility review
  • ✓ Legal risk assessment and conformance statement
  • ✓ Prioritized remediation roadmap
