# QA11Y Labs final logo

## Direction

This final mark merges the strongest elements from the recovered original and the current cleaner system:

- Original image: dark terminal feel, neon cyan QA11Y, gold Labs, subtle scan-line/code energy.
- Current site assets: shield/check symbol for trust, assurance, and accessibility testing.
- Document system: clean teal-forward professional style that works in reports, proposals, cards, and email.

## Files

- `qa11ylabs-logo-primary.svg` — primary lockup with tagline.
- `qa11ylabs-logo-horizontal.svg` — clean site/header lockup.
- `qa11ylabs-logo-icon.svg` — app icon, favicon, social avatar, small badge.
- `qa11ylabs-logo-email.svg` — compact email/card/document header version.

PNG exports are generated from these SVGs for immediate use.

## Recommended use

- Use `qa11ylabs-logo-horizontal.svg` on the website header.
- Use `qa11ylabs-logo-email.svg` in email signatures and business card layouts.
- Use `qa11ylabs-logo-icon.svg` for favicon/social/profile/avatar spots.
- Use `qa11ylabs-logo-primary.svg` for hero sections, proposal covers, and brand moments where the tagline has room.

## Brand notes

Keep the exact wordmark casing as `QA11Y Labs`. The cinematic brick-wall/terminal composition should remain hero art, not the everyday logo.
