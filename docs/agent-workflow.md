# Computer, Hermes, and OpenClaw Workflow

- Computer coordinates, makes judgment calls, and decides when to delegate.
- Hermes handles website/code production and deploy-prep work when it reduces cost or execution load.
- OpenClaw/Arch facilitates operations, Telegram commands, and brokered actions.
- The broker controls risky actions, production deploys, receipts, cooldowns, approval states, and rollback paths.
- Telegram is the primary channel for approval and important updates. The ops dashboard is the fallback visibility layer.
- Accessibility QA should prefer DOM, accessibility-tree, and session/video-intercept evidence before screenshots unless visual proof is required.
